**NodeGraph.jsx — Generate base layout using 21st.dev Magic component builder:**

Use `mcp__magic__21st_magic_component_builder` to generate the visual layout of a node graph / flow diagram component. Prompt it for: "A clean, minimal flow diagram component with rounded rectangle nodes connected by thin lines. Dark theme. Nodes have labels inside. Think Linear or Figma-style flow diagram. The graph flows left-to-right (or top-to-bottom) showing a process pipeline." After generation, customize:

- Accept `nodes` prop (array of { id, label, level, branch }) and `connections` prop (array of { from, to })
- Render as SVG with a responsive viewBox
- Nodes: rounded rectangles (rx: 8-12) with --bg-secondary fill, --border stroke, --text-primary label text. Size ~120x50px each.
- Connection paths: thin lines (strokeWidth 1.5-2) using --accent color, rendered as SVG `<path>` elements with class "connection-path"
- Layout algorithm: Position nodes based on `level` (horizontal position) and `branch` (vertical offset for branching paths). The graph branches at level 3 (Book Apt goes up-left, Send Quote goes down-right) and merges back at level 5 (Confirm).
- Node positions should be computed from the data — not hardcoded pixel positions. Use level * spacing for x, and branch offsets for y.
- The SVG should be centered in its container and scale responsively.
- On mobile, the graph may need to be simplified or scaled — Claude's discretion. Consider a narrower viewBox or hiding branch labels on very small screens.

**DemoPartTwo.jsx — Build the complete section:**

1. **Section header:** "Part II: System Logic" using demoParts[1] from `src/content/home.js`. Same header style pattern as DemoPartOne (uppercase tracking label, title, description).

2. **Node graph centered:** Render `<NodeGraph>` component with systemNodes and connections. Full width of the section container, with appropriate max-width for readability.

3. **GSAP Animation (viewport-triggered):**
   - Use `useGSAP` hook with `{ scope: containerRef }` — follow BackgroundPaths.jsx stroke-dashoffset pattern
   - Register ScrollTrigger: `gsap.registerPlugin(ScrollTrigger)`
   - Create timeline with `scrollTrigger: { trigger: containerRef.current, start: "top 75%", once: true }`
   - Wrap in `gsap.matchMedia()`:
     - `(prefers-reduced-motion: no-preference)`: Full animation sequence:
       a. Nodes fade in with stagger (0.1s between each, following the flow order by level)
       b. Connection paths animate with stroke-dashoffset (each path: get getTotalLength(), set strokeDasharray and strokeDashoffset to length, animate strokeDashoffset to 0)
       c. As each connection completes, the destination node gets a subtle glow (drop-shadow with --accent color) that fades after 0.5s
       d. Stagger connections by 0.25s so they draw sequentially following the flow
       e. Total animation: ~4-6 seconds
     - `(prefers-reduced-motion: reduce)`: All nodes and connections visible immediately (opacity fade 0.3s)
   - CRITICAL: Null-check paths before calling getTotalLength() — see Research pitfall #6

4. **Background:** Use --bg-primary. Subtle visual distinction from Part I section above (Claude's discretion).
