**DemoPartOne.jsx — Build the complete section:**

Create `src/sections/home/DemoPartOne.jsx` with the following structure:

1. **Section header:** "Part I: Customer Experience" using demoParts[0] from `src/content/home.js`. Style with uppercase tracking, accent color label, and the title/description below it.

2. **Two-column layout (desktop):** Left side = web form, right side = phone mockup with SMS.

   - Use Claude's discretion for exact breakpoint and spacing.

   - Import `formFields` from `src/content/demo-data.js`

   - Each field has a label and input styled with project design tokens (--bg-secondary background, --border, --text-primary)
   - Fields start with `opacity: 0` and `y: 20` — GSAP animates them in with stagger
   - After animation completes, each input should show the auto-filled value (Sarah Mitchell, etc.) with a subtle typing/reveal feel — use GSAP's TextPlugin or stagger the value appearance per field

4. **Phone mockup (right column):**
   - Import `smsConversation` from `src/content/demo-data.js`
   - Render inside `<PhoneMockup>` component
   - SMS bubbles: customer messages right-aligned with accent-colored background, system messages left-aligned with --bg-secondary background

   - Dark theme: screen background should be --bg-primary or slightly lighter, bubble text --text-primary

   - Use `useGSAP` hook with `{ scope: containerRef }` — follow BackgroundPaths.jsx pattern

   - Create timeline with `scrollTrigger: { trigger: containerRef.current, start: "top 80%", once: true }`
   - Wrap in `gsap.matchMedia()`:

     - `(prefers-reduced-motion: reduce)`: Instant fade-in (opacity only, duration 0.3s) for all elements simultaneously
   - Animation timing (Claude's discretion): ~3-5 seconds total for the full sequence

6. **Background:** Use --bg-primary as section background. Add subtle visual distinction from surrounding sections (Claude's discretion — could be a subtle gradient, border-top, or slight bg shift).
