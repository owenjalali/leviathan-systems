  <name>Task 1: Create useLiveMonitor polling hook</name>
  <files>src/hooks/useLiveMonitor.js</files>
  <action>
Create a React hook that polls the n8n endpoint for live demo data.

**Endpoint:** `https://systems.leviathan-systems.com/webhook/demo/latest?demo_session_id={sessionId}`

**Hook signature:**
```javascript
export function useLiveMonitor() {
  // Returns:
  // - data: current demo data object (or null)
  // - isPolling: boolean
  // - error: error message or null
  // - changedFields: array of field names that changed on last update
  // - startPolling: (sessionId) => void
  // - stopPolling: () => void
}
```

**Implementation requirements:**
1. Use `useRef` for:
   - `intervalRef` - stores setInterval ID for cleanup
   - `mountedRef` - prevents setState after unmount (memory leak prevention)
   - `sessionIdRef` - stores current session ID (avoids stale closure)
   - `prevDataRef` - stores previous data for change detection

2. `startPolling(sessionId)` function:
   - Stores sessionId in ref
   - Clears any existing interval
   - Sets up 1-second polling interval
   - Each poll: fetch endpoint, compare to prevData, update changedFields, update data

3. `stopPolling()` function:
   - Clears interval
   - Resets isPolling to false
   - Does NOT reset data (preserve final state for display)

4. Change detection logic:
   - Compare current response fields to prevDataRef
   - Return array of field names that differ (e.g., ['issue', 'urgency'])
   - Store current as prevData after comparison

5. Error handling:
   - Wrap fetch in try/catch
   - On network error: set error state, do NOT stop polling (transient failures)
   - Clear error on successful fetch

6. Cleanup on unmount:
   - useEffect cleanup clears interval
   - Sets mountedRef.current = false
   - Check mountedRef before any setState call

7. Post-call polling extension:
   - Export a `continuePollingFor(seconds)` function OR document that parent should call stopPolling after delay
   - The 30-second extension after call ends is managed by parent component, hook just provides start/stop

**Expected data shape from n8n:**
```javascript
{
  success: true,
  data: {
    status: "active_call" | "call_ended",
    issue: "string or null",
    urgency: "string or null",
    location: "string or null",
    intent: "string or null",
    summary: "string or null",
    timestamp: "ISO string"
  }
}
```

**Avoid:**
- Using useCallback for startPolling/stopPolling (not needed, refs handle staleness)
- Storing interval ID in state (causes re-renders)
- Polling without sessionId (guard against empty calls)

4. Call stopPolling and verify fetching stops

  </verify>
