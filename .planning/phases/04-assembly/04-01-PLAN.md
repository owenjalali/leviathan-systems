  <action>
Create DemoSection.jsx that coordinates state between VapiCallButton and LiveMonitorTerminal.

**State coordination pattern:**
- Component owns sessionId state (starts null, set by VapiCallButton)
- useLiveMonitor hook instance lives in DemoSection
- VapiCallButton receives onCallStart callback that receives sessionId
- DemoSection calls startPolling(sessionId) when call starts
- VapiCallButton receives onCallEnd callback
- DO NOT reset sessionId on call end (terminal needs it for 30-second polling window)
- Track callStatus from VapiCallButton to compute terminal status

**Terminal status logic:**
```javascript
const getTerminalStatus = () => {
  if (callStatus === 'active') return 'active'
  if (isPolling && !data?.data) return 'processing'
  if (data?.data?.summary) return 'captured'
  return 'standby'
}
```

**Layout structure:**
- Section wrapper: `py-32 sm:py-40 relative overflow-hidden`
- Top border separator: `absolute top-0 left-0 right-0 h-px bg-gradient-to-r from-transparent via-white/10 to-transparent`
- Container: `mx-auto max-w-6xl px-6 relative z-10`

- Grid: `grid lg:grid-cols-2 gap-8 lg:gap-12 items-start`
- Left column: VapiCallButton with onCallStart/onCallEnd callbacks
- Right column: LiveMonitorTerminal with data/isPolling/changedFields/status props

**Optional enhancements (if time permits):**

- Subtle background accent (radial gradient) like other sections
