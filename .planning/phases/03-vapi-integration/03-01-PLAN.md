Create `src/hooks/useVapiCall.js` following the pattern from RESEARCH.md:

**Hook API:**
```javascript
const {
  callStatus,      // 'idle' | 'connecting' | 'active' | 'ending'
  volumeLevel,     // 0-1 float for audio visualization
  error,           // Error object or null
  sessionId,       // Current session ID (null if no call)
  startCall,       // (assistantId, metadata?) => void
  stopCall,        // () => void
  clearError       // () => void - for retry functionality
} = useVapiCall(publicKey)
```

**Implementation requirements:**
1. Create Vapi instance in useEffect with publicKey, store in useRef (not useState)
2. Listen to events: call-start, call-end, volume-level, error
3. Generate session ID using `crypto.randomUUID()` in startCall
4. Pass session ID to Vapi via `variableValues.demo_session_id`
5. Track "connecting" state after startCall, "active" after call-start event
6. Track "ending" state after stopCall, "idle" after call-end event
7. Cleanup: call vapi.stop() in useEffect return
8. Preserve sessionId after call ends (for polling continuation)

**Vapi credentials (from PROJECT.md context):**
- Public key: `f76c6e6b-83ec-46f5-9a8c-8d1ea5ce770d`
- Assistant ID: `c2a02a7c-73f6-4fc3-915c-78f14a58c866`

**Error handling:**
- Set error state on error event
- clearError function to reset error state (for retry)
- Error auto-clear when new call starts

**Pattern from useLiveMonitor.js to follow:**
- mountedRef for safe state updates after unmount
- useCallback for startCall/stopCall
- Clean ref-based cleanup

Create `src/components/VapiCallButton.jsx` implementing the design from CONTEXT.md.

**Component API:**
```javascript
<VapiCallButton
  onCallStart={(sessionId) => void}  // Called when call actually starts
  onCallEnd={() => void}             // Called when call ends
  className=""                       // Optional additional classes
/>
```

**Button states (from CONTEXT.md):**

1. **Idle state:**
   - Solid accent button (bg-[#00d4cf])
   - Text: "Start Demo Call"
   - Phone icon from lucide-react

2. **Connecting state:**
   - Show spinner + "Connecting..."
   - Button disabled
   - Subtle pulse animation

3. **Active state:**
   - Transform to stop button (red/danger styling)
   - Text: "End Call"
   - Audio bars (equalizer-style) animating based on volumeLevel
   - Elapsed timer displayed (MM:SS format)
   - PhoneOff icon

4. **Ending state:**
   - Show "Ending..."
   - Button disabled

5. **Error state:**
   - Small error indicator with retry button
   - Auto-dismiss after 7 seconds
   - Does not replace main button, shows alongside

**Audio Bars implementation (from RESEARCH.md):**
- 5 bars with different height multipliers [0.6, 1.0, 0.8, 0.9, 0.5]
- Use CSS transform: scaleY() driven by volumeLevel
- Minimum 20% height when active (not speaking)
- Transition duration: 100ms
- Bars colored with accent color (#00d4cf)

**Elapsed Timer:**
- Create inline useElapsedTime hook (or include in component)
- Start counting when callStatus === 'active'
- Reset to 0 when call ends
- Format as M:SS (e.g., "1:23")

**CSS additions to src/index.css:**
Add idle animation for audio bars when call is active but AI not speaking:
```css
@keyframes bar-idle {
  0%, 100% { transform: scaleY(0.15); }
  50% { transform: scaleY(0.25); }
}

.animate-bar-idle {
  animation: bar-idle 1.2s ease-in-out infinite;
}
```

**Internal structure suggestion:**
- AudioBars subcomponent (takes volumeLevel, isActive props)
- ErrorDisplay subcomponent (takes error, onRetry, onDismiss props)
- Main VapiCallButton using useVapiCall hook

**Styling notes:**
- Follow design system: use CSS variables for colors
- Button should be substantial (py-3 px-6 or similar)
- Rounded corners (rounded-lg)
- Hover states for idle button
- Disabled states should be visually distinct
